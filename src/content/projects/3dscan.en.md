3DScan is a 3D reconstruction project that builds digital models from real-world objects using RGB-D data and point-cloud registration.

## How it works

- **RGB-D capture** — fuse multiple views into a single point cloud.
- **Registration** — align scans using ICP (Iterative Closest Point).
- **AR-based** — the scanning flow uses augmented reality to guide capture.
